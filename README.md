## 🚀 Featured Projects

### 🏢 SocietyPay — AI-Powered Society Management Platform

> A production-grade full-stack mobile platform that automates residential society management using ML, NLP, and scalable backend infrastructure

**The Problem:**
- Complaints getting lost in WhatsApp groups
- Manual Excel sheets for payment tracking
- No way to predict who will default on maintenance

**What I Built:**

| Feature | Tech |
|---------|------|
| 📱 Mobile App | React Native + TypeScript |
| ⚙️ Backend API | Node.js + Express + JWT |
| 🗄️ Database | MongoDB Atlas + Mongoose |
| 🧠 NLP Complaint Routing | Python + Naive Bayes + CountVectorizer |
| 💰 Payment Risk Prediction | Scikit-learn + FastAPI |
| 💳 Payments | Razorpay + signature verification |
| 🛡️ Visitor Security | Isolation Forest anomaly detection |

### Infrastructure & Scalability

- ⚡ Redis caching for faster API responses
- 🚦 API rate limiting for abuse prevention
- 🔄 BullMQ background job processing
- 🐳 Dockerized backend services
- ☁️ AWS EC2 deployment with Nginx reverse proxy
- 🔁 GitHub Actions CI/CD workflows

**Results:**
- Complaints auto-categorized and routed instantly
- Payment defaulters flagged before they miss payment
- Visitor behavior analyzed in real time with ML

### SocietyPay Architecture

```
User Request
     ↓
    DNS
     ↓
    CDN
     ↓
Load Balancer
     ↓
   Nginx (reverse proxy)
     ↓
 Node.js API
   ↓       ↓
Redis    BullMQ (background jobs)
   ↓       ↓
      MongoDB Atlas
```
